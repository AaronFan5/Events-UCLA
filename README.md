# Events-UCLA
Our group’s proposed project is to make a Shiny App that tracks events on UCLA’s campus. The app will behave similarly to Google Maps, except it will only display a map of UCLA’s campus (similar to below).

The user will be able to zoom into the map and move around, as well as have a live GPS that can show the user’s current location. The user will be able to mark locations on the map (similar to how you can pin on Google Maps).

After marking a location, an interface will show up where users can put a Title, Description, Image(s), and the Duration. The intent of this is to allow the user to mark any on-campus events that are occurring, which will then display for all users on the app campus. Alternatively, if a user wants to advertise their own event in advance, they can schedule a pin which will then show users that “X EVENT” is happening at “X TIME”. If there is extra time, we may also include an account creation process where users can locally save pins on the map (to display where and when their classes are), however, that would be a supplementary feature to the main intent of this app. 
After doing some research, we will likely be using the leaflet library (https://rstudio.github.io/leaflet/) in order to create the map interface and to implement the GPS feature. Since it is a Shiny App, we will obviously use Shiny as well as DBI + an RSQL library in order to save and retrieve the data. We will use Supabase as the SQL container such that the app will be able to connect to the cloud. We will not be using a premade dataset; instead, we will have users upload their OWN data (through the pins) in an SQL format that will then be parsed and subsequently loaded from Supabase.
